# C-IDE

A single-user interactive C development environment with a custom C compiler and a C-based backend.

## Overview

C-IDE is a college Compiler Design project focused on building a lightweight programming environment for writing, compiling and running C programs.

The project is divided into three main parts:

* **Frontend** — React + TypeScript + Vite
* **Backend** — C-based server and process management
* **Compiler** — A custom C compiler implemented in C

## Project Structure

```text
c-ide/
├── frontend/     # React frontend
├── backend/      # C backend
├── compiler/     # Custom C compiler
└── docs/         # Project documentation
```

## Planned Features

* C code editor
* Syntax highlighting
* File explorer
* Compile and run C programs
* Compiler error reporting
* Terminal/output panel
* Resizable IDE panels
* Theme switching
* Custom C compiler
* Process management and execution isolation
